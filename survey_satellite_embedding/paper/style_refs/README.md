# Survey Writing Style References

This folder is intentionally flat: keep downloaded PDFs directly in
`survey_satellite_embedding/paper/style_refs/` instead of sorting them into
venue or topic subdirectories.

The collection below is restricted to high-impact remote-sensing review papers,
primarily from `Remote Sensing of Environment` (RSE) and `ISPRS Journal of
Photogrammetry and Remote Sensing` (ISPRS JPRS). MDPI `Remote Sensing` papers
are intentionally excluded.
